# v3.4.0 用户体验批量改进 实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 落地 7 条用户反馈:四页合一、通知渠道列表化(同渠道多账号)、自备份上云+删除、弹窗防误关、计划立即执行、连接表单顺序/检测门控、版本号统一 3.4.0。

**Architecture:** 后端先加云适配器列举能力与自备份上云/轮转,再重构通知为渠道表(模型+发送遍历 → API+旧配置迁移);前端随后改 Settings 页、连接表单,最后把 Schedules/History/Restore 三页并入 Backups 壳页面(三 Tab,状态进 URL query)。

**Tech Stack:** FastAPI + SQLAlchemy 2.0 + SQLite / Vue 3 + TS + Naive UI / pytest / vue-tsc。

**Spec:** `docs/specs/2026-11-01-v3.4.0-ux-batch-design.md`(执行者需同时读 spec 与本计划)。

## Global Constraints

- Python ≥3.11;不新增第三方依赖。
- 密钥一律 Fernet 加密存储、API 响应永不回传明文、编辑留空不覆盖已存密文。
- SQLite:`create_all` 只建新表,旧表补列走 `maintenance._ensure_column`(本计划旧表零改列)。
- 每任务一个中文提交:`type(scope): 描述`,type ∈ feat/fix/refactor/docs/chore/test。
- 每任务结束其测试绿;Task 9 前跑全量 `pytest` + `cd frontend && npm run build`(vue-tsc)。
- 前端移动端沿用现有 mcard 卡片模式与 `useBreakpoint().isMobile` 分支。

## Review Focus

1. **渠道编辑留空 secret 不得清空已存密文** —— Task 4 `test_channel_update_secret_blank_keeps_stored`。
2. **用户删光渠道后重启不得被旧配置复活** —— Task 4 `test_migrate_runs_once_marker`(app_settings 一次性标记)。
3. **云端轮转只删白名单名 `app-YYYYMMDD-HHMMSS.(db.gz|sql)`,同前缀其他对象不动** —— Task 2 `test_upload_rotates_beyond_30`(夹带非白名单对象)。
4. **`list_prefix` 返回去掉 `cfg.prefix` 的用户空间 key,可直接喂 `delete`** —— Task 1 `test_s3_list_prefix_strips_dest_prefix` / `test_shares_list_prefix`。
5. **全局开关关闭时一条不发;单渠道抛异常不阻断其余渠道** —— Task 3 `test_notify_iterates_enabled_channels`。
