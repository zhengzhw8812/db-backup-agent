## Review Focus

1. **云删除误删**:只允许删除 `key == rec.file_path` 且 SyncTarget 属于同一 connection 的对象 — Task 1 测试 pin;
2. **验证假通过**:篡改文件内容(字节数不变)必须 failed(checksum 比对),截断损坏必须 failed(gzip CRC)— Task 2 两个独立用例;
3. **看门狗误报**:阈值内 / 无成功记录但 <48h / 24h 内已告警 / 计划停用,四种情形都必须静默 — Task 4 测试 pin;

5. **`/docs` 泄露**:默认 404,仅 `APP_DOCS_ENABLED=true` 开启 — Task 5 测试 pin。
