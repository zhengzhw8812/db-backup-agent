# v3.3 前端响应式与视觉改版设计

- **日期**: 2026-10-02
- **状态**: 待审阅
- **参考**: SoybeanAdmin(同栈 Vue3+Naive UI 标杆:移动抽屉侧栏/折叠/主题)、移动优先实践(单列 ≤768、宽表格转卡片、44px 触控目标)。

## 1. 布局架构(AppLayout 重写)

- **断点**:新增 `frontend/src/composables/useBreakpoint.ts` — `matchMedia("(max-width: 1023px)")` 单例响应式,导出 `isMobile`(<1024)与 `isDesktop`;
- **桌面(≥1024)**:`n-layout-sider` 220px,可折叠至 64px(顶部折叠按钮,collapse 状态存 localStorage);菜单折叠时仅图标(加图标到菜单项);
- **移动(<1024)**:侧栏不渲染,顶栏左侧汉堡按钮打开 `n-drawer`(内含同一菜单);路由跳转/选中后自动关闭;
- **深色修复**:内容区移除硬编码 `background:#f8fafc`,改用 `n-layout` 内置主题化(`theme` 由 useTheme 传入 layout 组件树,已有 naive-provider 则对齐);`darkOverrides` 补 `bodyColor/cardColor`;
- 顶栏:左=汉堡(仅移动)+页面标题;右=主题切换/用户名/登出(既有)。

## 2. 移动端表格卡片化(6 页)

Backups、Restore、History、Connections、Schedules、CloudSync:`isMobile` 为真时渲染卡片列表(NCard 堆叠:主字段 + 状态标签 + `size="large"` 操作按钮),为假时保持 NDataTable。页面内 `v-if` 切换;卡片字段按各页信息密度定制;状态标签复用 `useStatusTag`。

## 3. 视觉升级

- 新组件 `frontend/src/components/PageHeader.vue`(title + description + 右侧 actions 插槽),十页统一接入;
- 页面内容容器统一 n-card 化、间距 16px(主题圆角);
- Dashboard 图表区改 `n-grid cols="1 s:2" x-gap=16 y-gap=16` 响应式分栏;
- 触控目标:关键操作按钮移动端 `size="large"`。

## 4. 验证

vue-tsc 构建全绿;E2E 容器回归(/docs 无暴露、SPA 200、登录 200);移动端人工检查清单归档 `~/.plans/evidence/`(后续可选 Playwright 截图自动化,本批次不做)。

## 5. 不做(YAGNI)

换 UI 框架/引入 UnoCSS、i18n、登录页改版(v3 已重设计)、图标库新依赖(菜单用 emoji,沿用现状)、Playwright。

## 6. 风险

| 风险 | 缓解 |
|---|---|
| 深色模式回归(硬编码色清理波及多页) | 色值全部收口到主题/token;逐页过视觉清单 |
| 卡片化遗漏字段 | 每页卡片字段对照桌面表格列逐一映射(实现清单) |
| 抽屉内菜单滚动/遮挡 | drawer width 240,内容滚动;路由切换关闭 |
